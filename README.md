# FutCombo

Loja de camisas de time em Planaltina, Goiás: fundo escuro, dourado e catálogo de varejo e atacado.

## Stack

- Next.js 15 (App Router)
- React 19
- Tailwind CSS 4
- TypeScript

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

## Publicação

1. Envie o repositório para o GitHub (`davidfgalvao/futcombo`).
2. Importe o projeto na Vercel (conta `brunodab10-7017`) ou rode `npx vercel --prod`.
